----------------  BACKUP ComfyUI -------------------
1. Install Zstandard:
   ```bash
   sudo apt update && sudo apt install zstd
   ```
2. Create the archive:
   ```bash
   tar -I 'zstd -T0' -cf archive_name.tar.zst /path/to/your/folder
   ```
   *(Explanation: `tar` bundles the 50,000 files together, `-I 'zstd -T0'` tells it to compress using Zstandard and `-T0` tells it to use **every available CPU core** on your system. `-cf` means create file).*

**To extract later:** `tar -I 'zstd -T0' -xf archive_name.tar.zst`
